# dinner-truce-privacy

Public host for the Dinner Truce Android app privacy policy (GitHub Pages).
The app itself is developed in a private repository; only this policy page is
published here.

Live page: https://medinaluis85.github.io/dinner-truce-privacy/

The page content mirrors `docs/PRIVACY_POLICY.md` from the app repository —
republish it by copying that file's content into `index.html` (drop the repo
metadata header and the OWNER note at the bottom) whenever the policy changes,
then verify the live URL actually updated.
